# My Personal Blog

Welcome to my personal blog! This is a simple HTML and CSS website where I share my thoughts, images, and videos.

## Features
- Home/About Me section
- Blog posts with images
- Embedded videos
- Contact info with social links

## Setup
1. Clone the repository.
2. Open `index.html` in a web browser.
3. Replace placeholder content with your own (images, videos, text, links).
